Data Safety & Security Architecture

Standard: Hive Binary Local Database Google Play Safety Section Verified

1. Security Philosophy

Finey was engineered from line one with a fundamental premise: The safest place for your personal financial data is strictly on your device. By eliminating remote backend servers, we remove the vulnerability vector of cloud database data breaches.

2. Technical Storage Architecture

  • Hive Key-Value Database: All transaction records, expense entries, budgets, and category preferences are written in optimized binary format inside your device's isolated application storage box.
  • Operating System Sandboxing: Android and iOS isolate Finey's app storage box using operating system sandboxing primitives, preventing unauthorized apps on your phone from inspecting your financial records.
  • Zero Remote Transmissions: Finey does not make background HTTP/HTTPS API calls to remote analytics or ad servers.

3. Google Play Data Safety Declaration Guidance

If you are submitting Finey to Google Play Console, use these exact parameters for the Data Safety Form:

  • ✅ Does your app collect or share user data? Select No.
  • ✅ Is all data stored locally on the device? Select Yes.
  • ✅ Does the app require user accounts or login? Select No.

4. Data Portability & User Backup

You can generate a structured CSV file anytime. The CSV export is generated locally on device memory and saved directly to your device's documents folder without passing through any external network.
